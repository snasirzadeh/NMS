# Start Codex

From this repository root, start Codex and give it:

```text
Read AGENTS.md, docs/PLAN.md, and prompts/phase-01-architecture.md.

This is a new project.
Implement Phase 1 only.

Inspect the current repository first.
Replace docs/architecture.md with the architecture you recommend.
Do not begin Phase 2.
```

After you review Phase 1, use:

```text
Read AGENTS.md, docs/PLAN.md, docs/architecture.md,
and prompts/phase-02-foundation.md.

Implement Phase 2 only.
Run the relevant tests/builds.
Do not begin Phase 3.
```

Repeat the same pattern for each phase.
